          Бот для Fortnite: катает за тебя, пока ты отдыхаешь

Версия 1.6.5
Поддержка и покупка ключей: Telegram @kk4ose

Всё займёт 10–15 минут, большая часть — ожидание установки.
Делай по шагам сверху вниз, ничего не пропускай.


---------------------------------------------------------------------
 ШАГ 1. УСТАНОВИ PYTHON (один раз)
---------------------------------------------------------------------
Python — это программа, на которой работает бот. Без неё никак.

1. Открой сайт:  https://www.python.org/downloads/windows/
   (НЕ жми большую жёлтую кнопку на главной — там слишком новая версия,
    под неё ещё нет нужных библиотек!)
2. Найди в списке "Python 3.13.x" (любую 3.13) и нажми
   "Download Windows installer (64-bit)".
3. Запусти скачанный файл (python-3.xx-amd64.exe).
4. !!! САМОЕ ВАЖНОЕ !!!
   В первом окне установщика ВНИЗУ поставь галочку:
       [x] Add python.exe to PATH
   Без этой галочки бот НЕ запустится.
5. Нажми "Install Now" и дождись конца установки.
6. Если в конце есть кнопка "Disable path length limit" — нажми её.
7. Нажми "Close".

Проверка (по желанию):
   Нажми Win + R, напиши  cmd  и Enter.
   В чёрном окне напиши:  python --version  и Enter.
   Если видишь "Python 3.xx" — всё установилось правильно.
   Если пишет "не является внутренней или внешней командой" —
   переустанови Python и НЕ ЗАБУДЬ галочку "Add python.exe to PATH".


---------------------------------------------------------------------
 ШАГ 2. РАСПАКУЙ ПРОГРАММУ
---------------------------------------------------------------------
1. Скачай архив с программой (AfkToken_v1.6.5.zip).
2. Нажми на архив правой кнопкой -> "Извлечь всё..." -> "Извлечь".
   НЕ запускай файлы прямо из архива — сначала распакуй!
3. Положи папку куда удобно, например на Рабочий стол или в Документы.
   Лучше, чтобы в пути к папке не было русских букв и пробелов,
   например:  C:\AfkToken


---------------------------------------------------------------------
 ШАГ 3. ПЕРВЫЙ ЗАПУСК
---------------------------------------------------------------------
1. Открой папку с программой и дважды нажми на  start.bat
2. Если Windows пишет "Система Windows защитила ваш компьютер":
   нажми "Подробнее" -> "Выполнить в любом случае".
3. Откроется чёрное окно — начнётся установка библиотек.
   ПЕРВЫЙ раз это занимает 5–10 минут (качается ~1 ГБ). Ничего не
   трогай и НЕ закрывай чёрное окно, пока не откроется программа.
4. Откроется окно Afk token в новом стиле «Стекло».
   Если вместо него открылось старое окно — ничего страшного, всё
   работает так же. Новому окну нужен компонент Microsoft Edge WebView2
   (на Windows 10/11 он почти всегда уже есть).
5. Следующие запуски — за пару секунд.

Чёрное окно не закрывай, пока работает бот — это часть программы.


---------------------------------------------------------------------
 ШАГ 4. АКТИВАЦИЯ
---------------------------------------------------------------------
БЕСПЛАТНО (без ключа):
   Работают авто-запуск катки и прыжок с автобуса.

Premium и Ultimate (по ключу, навсегда):
   Premium — все основные функции: пропуск наград, анти-AFK, бег и
             сундуки, перезапуск при ошибке, скрины и Telegram и др.
   Ultimate — всё из Premium + обход препятствий, плавная мышь,
             уход от зоны, выход, если остался один в команде,
             точка высадки, спринт, низкая графика на время фарма.
   Цены и покупка — во вкладке "Магазин" в программе или у @kk4ose.

Как активировать:
   1. Купи ключ во вкладке "Магазин" или напиши @kk4ose.
   2. Вставь ключ (вида AFK-XXXX-XXXX-XXXX-XXXX) в окно активации
      и нажми "Активировать".
   3. Внизу слева появится твой уровень: Premium или Ultimate.
   Ключ работает навсегда, но только на ОДНОМ компьютере.
   Старые VIP-ключи продолжают работать.
   Для платных функций нужен интернет: уровень ключа проверяется
   на сервере. Без интернета работают только бесплатные функции.


---------------------------------------------------------------------
 ШАГ 5. НАСТРОЙ FORTNITE (обязательно!)
---------------------------------------------------------------------
1. Fortnite -> Настройки -> Видео -> Режим окна:
       "Оконный без рамок"
   В обычном "Полноэкранном" режиме бот НЕ видит экран.
2. Язык игры: русский или английский.
3. Режим (Соло / Дуо / Трио / Отряды) выбирается в Afk token:
   "Настройки" -> "Катка" -> "Режим в лобби".
   Если играешь без друзей — в игре включи "Заполнить".


---------------------------------------------------------------------
 ШАГ 6. ЗАПУСК БОТА
---------------------------------------------------------------------
1. Открой Fortnite и дождись лобби.
2. В Afk token во вкладке "Функции" включи нужные функции
   переключателями (вкладки Основные / Premium / Ultimate).
   Настройки сохраняются сами.
3. Нажми "СТАРТ".
4. Первый раз бот скачает распознавание текста (~100 МБ) —
   подожди 1–3 минуты, пока статус не станет "Бот работает".
5. Всё! Отходи от ПК. Мышь и клавиатуру во время работы лучше
   не трогать.

Горячие клавиши (работают даже из игры):
   F9   — пауза / продолжить
   F10  — остановить бота


---------------------------------------------------------------------
 НАГРАДЫ И ОТЧЁТЫ В TELEGRAM (Premium, по желанию)
---------------------------------------------------------------------
1. В Telegram найди @BotFather -> напиши /newbot -> придумай имя.
   Он пришлёт ТОКЕН (длинная строка вида 123456789:AAH...).
2. В Afk token -> "Функции" -> Premium -> "Награды в Telegram" -> вставь токен.
3. Открой своего нового бота в Telegram и нажми "Start".
4. В программе нажми "Найти мой Chat ID", потом "Тест".
5. Включи переключатель. Теперь награды и отчёты приходят в Telegram.


---------------------------------------------------------------------
 ЧАСТЫЕ ПРОБЛЕМЫ
---------------------------------------------------------------------
"Need Python 3.13" / ничего не происходит при запуске start.bat
   -> Python не установлен или не стояла галочка "Add python.exe
      to PATH". Переустанови Python (Шаг 1) с этой галочкой.

Ошибка "CERTIFICATE_VERIFY_FAILED" / не скачивается
   -> Мешает антивирус (проверка HTTPS). На время первого запуска
      отключи в антивирусе "веб-защиту / проверку HTTPS",
      потом включи обратно.

"Install failed" при установке библиотек
   -> Проверь интернет и запусти start.bat ещё раз.
      Если не помогло — удали в папке файл .installed (если есть)
      и запусти снова.

"Не хватает места на диске" / No space left on device
   -> Освободи 1–2 ГБ на диске, где лежит программа (модели распознавания
      хранятся в папке программы, в папке models).

"Уже установлена другая версия этого продукта" при установке Python
   -> Python 3.13 у тебя уже стоит — просто запускай start.bat.

Бот запущен, но ничего не нажимает
   -> Fortnite должен быть в режиме "Оконный без рамок" (Шаг 5).
   -> Окно игры должно быть видно на экране, не свёрнуто.

Открылось старое окно вместо нового
   -> Нет компонента WebView2. Скачай "Microsoft Edge WebView2 Runtime"
      с сайта Microsoft (Evergreen Bootstrapper), установи и
      перезапусти start.bat. Старое окно тоже полностью рабочее.

Бот не видит какую-то кнопку
   -> Пришли @kk4ose скрин этого экрана и файл
      logs\afk_token.log из папки программы — поправлю.

"Ключ уже активирован на другом компьютере"
   -> Ключ привязан к одному ПК. Сменил ПК или переустановил
      Windows — напиши @kk4ose, сброшу привязку.
