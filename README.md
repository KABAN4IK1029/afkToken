# Afk Token — AFK-бот для Fortnite

Автоматический бот для Fortnite: катает за тебя, пока ты отдыхаешь.  
Система ключей, админ-панель, пульт в Telegram, статистика и авто-обновления.

## 📥 Установка (Windows)

Всё займёт **10–15 минут**.

### 1. Установите Python
1. Скачайте **Python 3.13.x** с https://www.python.org/downloads/windows/
2. В установщике обязательно поставьте галочку: `[x] Add python.exe to PATH`
3. Нажмите «Install Now»

### 2. Распакуйте программу
1. Скачайте архив `AfkToken_v1.7.6.zip`
2. Распакуйте в удобную папку (например, `C:\AfkToken`)
3. **Не запускайте файлы напрямую из архива** — сначала распакуйте!

### 3. Первый запуск
1. Дважды нажмите `start.bat`
2. Если Windows заблокирует запуск — нажмите «Подробнее» → «Выполнить в любом случае»
3. Дождитесь установки библиотек (первый раз 5–10 минут)
4. Откроется окно Afk Token

### 4. Активация Premium / Ultimate
1. Купите ключ у поддержки: [@kk4ose](https://t.me/kk4ose)
2. В программе нажмите «Активировать ключ» и вставьте код
3. Ключ привязан к одному ПК. При смене компьютера — напишите в Telegram, сброшу привязку.

## 📱 Управление через Telegram

В настройках бота укажите:
- **Токен бота** (от @BotFather)
- **Ваш Chat ID**

Доступные команды:
- `/status` — состояние бота
- `/screen` — скриншот экрана
- `/start` / `/stop` / `/pause` — управление работой
- `/chests` — сундуки вкл/выкл
- `/goal` — цель фарма
- `/off60` — выключить ПК через час

## ❓ Частые проблемы

| Проблема | Решение |
|----------|---------|
| Ошибка при запуске `start.bat` | Поставьте галочку «Add python.exe to PATH» при установке Python |
| «CERTIFICATE_VERIFY_FAILED» | Временно отключите веб-защиту в антивирусе |
| Бот ничего не нажимает | Fortnite должен быть в режиме «Оконный без рамок» |
| Открылось старое окно | Установите Microsoft Edge WebView2 Runtime |
| Ключ уже активирован на другом ПК | Напишите @kk4ose, сброшу привязку |
